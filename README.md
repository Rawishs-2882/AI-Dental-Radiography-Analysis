# AI-Dental-Radiography-Analysis

AI-powered system analyzing dental radiographs using Artificial Neural Networks (ANN) and association rule mining, leveraging support, confidence, and lift metrics.

## Features
- ANN-based radiograph analysis
- Association rule mining over extracted findings
- Support, confidence, and lift metric evaluation

## Tech Stack
TensorFlow/Keras, mlxtend (association rule mining), OpenCV

## Setup & Run
1. `pip install -r requirements.txt`
2. Place radiograph images in `/data`.
3. Run `python analyze.py` to run the ANN classifier and generate association rules.
